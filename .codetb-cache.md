### State Management Approach
**Riverpod 2.x with StateNotifier pattern**

```
User Action
    ↓

    ↓
```

### Auth State Flow

```
┌─────────────────┐
│  App Startup    │
└────────┬────────┘
         ↓
┌─────────────────────────────────────────────────────────┐
│  AuthNotifier._init()                                   │
│  1. Check Supabase currentUser                          │
│  2. If exists → _loadProfile(user)                      │
│  3. If null → AuthUnauthenticated                       │
└─────────────────────────────────────────────────────────┘
         ↓
┌─────────────────────────────────────────────────────────┐
│  _loadProfile() Validation Chain:                       │
│  1. Fetch profile from 'profiles' table                 │
│  2. If profile null → Sign out, show error              │
│  3. If role == super_admin → Allow all                  │
│  4. If role != super_admin:                             │
│     a. Check clinic_id exists                          │
│     b. Fetch clinic status                             │
│     c. Verify is_active == true                        │
│     d. Verify subscription_ends_at > now               │
│  5. If any fail → Sign out, show specific error        │
└─────────────────────────────────────────────────────────┘
         ↓
┌─────────────────────────────────────────────────────────┐
│  State = AuthAuthenticated(user, profile)              │
│  → Triggers RouterRefreshListenable                    │
│  → GoRouter.rebuild()                                  │
│  → Route guards re-evaluate                            │
└─────────────────────────────────────────────────────────┘
```

### Workspace State Flow

```
WorkspaceScreen loads
    ↓
workspaceProvider(patientId) created
    ↓
WorkspaceNotifier constructor
    ↓
_loadData():
  - getNotes(patientId) → List<WorkspaceNote>
  - getConnections(patientId) → List<NoteConnection>
    ↓
State = WorkspaceState(notes, connections)
    ↓
UI renders:
  - GridPainter (dot background)
  - ConnectionsPainter (bezier curves)
  - Node widgets (positioned absolutely)
    ↓
User interaction:
  - Drag → updateNoteLocal() → immediate UI update
  - Drop → updateNoteInDb() → persist to Supabase
  - Add node → addNote() → refresh state
```

### API Communication Pattern

**Supabase Client Usage:**
```dart
// Singleton access
final SupabaseClient _client = Supabase.instance.client;

// Query pattern
final response = await _client
    .from('table_name')
    .select('*, relation(*)')  // JOINs with relationships
    .eq('column', value)       // WHERE clause
    .order('column', ascending: bool);  // ORDER BY
```

**Table Operations:**
- `select()` - Read
- `insert(data)` - Create
- `update(data).eq('id', id)` - Update
- `delete().eq('id', id)` - Delete

### Routing Flow

```
App Launch
    ↓
RouterRefreshListenable watches authProvider
    ↓
GoRouter.redirect() callback
    ↓
Check auth state (isAuthenticated?)
    ↓
If NOT authenticated:
  - /login → continue
  - any other → redirect to /login
    ↓
If authenticated:
  - /login → redirect to / or /super-admin (based on role)
  - /super-admin/* → verify role == super_admin
  - Receptionist → block /visits, /workspace, /settings, /ai
  - Doctor → block /settings/users
```

```dart

Future<void> deleteNote(String id) async {
  // Remove locally first (optimistic)
  state = state.copyWith(
    notes: state.notes.where((n) => n.id != id).toList(),
  );
  
  try {
    await _service.deleteNote(id);
  } catch (e) {
    state = state.copyWith(error: e.toString());
    await _loadData(); // Reload to restore if failed
  }
}
```
